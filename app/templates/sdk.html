JavaScript SDK

Drop-in browser agent for real-time attack detection. Monitors XHR, fetch, form inputs, DOM mutations, and errors — and streams events to Courra-Sec.

Quick Start
1
Add the script tag

Place this in the <head> of every page you want to monitor. 

<script src="http://YOUR-COURRA-SEC-HOST:5001/courra-sec-sdk.js"></script>
2
Initialize

Call Courra-SecSDK.init() once after the script loads. 

Courra-SecSDK.init({
  endpoint:  "http://YOUR-COURRA-SEC-HOST:5001/ingest",
  apiKey:    "YOUR_INGEST_API_KEY",   // matches INGEST_API_KEY env var
  appId:     "my-app",
  debug:     false
});
3
Optionally attach a user
// Call after login
Courra-SecSDK.setUser({ id: "user-123", role: "admin" });
Configuration Options
Option Type Default Description
endpoint string :5001/ingest Full URL of the Courra-Sec /ingest endpoint
apiKey string "" Sent as X-Courra-Sec-Key header. Must match INGEST_API_KEY
appId string "web" Identifies the monitored application in logs
batchSize number 10 Flush queue after this many events
flushInterval number 5000 Periodic flush in milliseconds
dedupWindow number 30000 Suppress identical events within this window (ms)
debug boolean false Log SDK activity to the browser console
Public API
Courra-SecSDK.init(config)

Initialize and activate the SDK. Must be called once before any other method.

Courra-SecSDK.init({ endpoint: "...", apiKey: "...", appId: "my-app" });
Courra-SecSDK.setUser(user)

Attach user context to all subsequent events.

Courra-SecSDK.setUser({ id: "user-42", role: "admin", name: "Alice" });
Courra-SecSDK.captureEvent(event)

Manually report a custom security event.

Courra-SecSDK.captureEvent({
  attackType: "privilege_escalation",
  endpoint:   "/admin/users",
  severity:   "high",
  payload:    "attempted role change to admin"
});
Courra-SecSDK.captureError(error, context)

Report a JavaScript error with optional context object.

try {
  riskyOperation();
} catch (err) {
  Courra-SecSDK.captureError(err, { component: "checkout", userId: "u-99" });
}
Courra-SecSDK.flush()

Immediately send all queued events without waiting for the next interval.

// Force-send before a critical navigation
Courra-SecSDK.flush();
Auto-Detected Events

The SDK hooks into the browser automatically. No additional code needed for these.

XHR & Fetch Monitoring
  • Scans request URLs and bodies for attack patterns
  • Captures 4xx / 5xx error responses
  • Detects payload injection before the request is sent
Form & Input Scanning
  • Inspects all form field values on submit
  • Reports the field name, value, and matched pattern
JavaScript Errors
  • Uncaught exceptions via window.onerror
  • Unhandled promise rejections
  • Includes stack trace and file/line info
DOM & Page Security
  • MutationObserver detects dynamically injected <script> tags
  • Clickjacking detection (self !== top)
Attack Patterns Detected
XSS SQL Injection Path Traversal Command Injection HTTP 4xx/5xx DOM Script Inject Clickjacking JS Errors Custom Events
Event Payload Structure

Each event sent to /ingest looks like this:

{
  "ipAddress":  "<client IP resolved server-side>",
  "attackType": "xss_attempt",
  "endpoint":   "/search?q=...",
  "severity":   "high",
  "payload":    "<script>alert(1)</script>",
  "source":     "courra-sec-sdk",
  "appId":      "my-app",
  "sessionId":  "sdk-a3f9...",
  "user":       { "id": "u-42", "role": "admin" },
  "url":        "https://app.example.com/search",
  "userAgent":  "Mozilla/5.0 ..."
}
