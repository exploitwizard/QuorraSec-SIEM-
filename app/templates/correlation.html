Correlation Rules

Detect multi-event patterns within time windows (e.g. brute-force → success = account takeover)

How correlation rules work

Each rule defines conditions that an event must match to count. When N or more matching events from the same group field (e.g. same IP) arrive within the time window, the rule fires and creates an alert.
